# CLAUDE.md

This repository is a Jekyll site published with GitHub Pages: a daily global markets
briefing plus a weekly recap every Monday.

- When you run as the scheduled daily routine, follow `ROUTINE.md` exactly.
- Sources and the source blocklist are in `SOURCES.md`.
- Post templates are in `templates/`. Posts go to `_posts/`.
- The repository is public and the site is public. Never commit personal holdings,
  ISINs, position sizes or account details.
